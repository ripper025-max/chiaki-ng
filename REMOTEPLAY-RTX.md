# RemotePlay Native RTX (experimental)
This branch adds optional NVIDIA RTX Video Super Resolution and GPU optical-flow interpolation. Source modules rtxvsr, ngxcore, gputimer, vkguard and flowfg are adapted from https://github.com/windystrife/chiaki-ng-ultimate/tree/ae63504b3db53b63de8f6f03ce6fa58d248bb894 (mirror of chiaki-ng-enhanced), under that project's AGPL/OpenSSL license; no executable from that repository is fetched. Integration code is separate. This is not an independent security audit.
NGX development files are obtained from the official NVIDIA/DLSS repository at commit 9981c6350dc58c0ce21f024fd65e31e851c31689. The NVIDIA runtime nvngx_vsr.dll is not bundled. Obtain it from NVIDIA's official RTX Video SDK https://developer.nvidia.com/rtx-video-sdk and place it beside chiaki.exe. The app checks Authenticode and the NVIDIA signer before enabling VSR. Restart app after placing runtime. Vulkan and SDR stream are required, and output must exceed source dimensions. Modes 1-4 only. No unofficial DLL or driver patch.
Frame generation uses vendor-neutral GPU optical flow, not NVIDIA DLSS FG or FRUC. Enable Frame Queue, restart, Vulkan renderer, then enable optical-flow generation. Requires high refresh display and real adjacent frames. Only SDR source up to 1080p, with regular rendering fallback. VSR takes effect on frames without optical-flow interpolation. Both are off by default. Latency can increase. No GPU, console or performance validation yet. This experimental branch is separate from the working native release.
